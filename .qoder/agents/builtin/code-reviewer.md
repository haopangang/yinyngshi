# 阴阳师辅助脚本 - 代码审查规范

## 审查重点

### 1. 设备控制层 (`src/device/`)
- ADB 连接是否有重试机制
- 超时处理是否合理（设备无响应、命令卡死）
- 截图/点击操作是否有异常捕获
- 设备断连后的自动重连逻辑

### 2. 视觉识别层 (`src/vision/`)
- 模板匹配的阈值是否合理（太高漏检、太低误检）
- 多尺度匹配的性能开销
- OCR 识别结果是否有校验（数字范围、文字合理性）
- 图像预处理是否充分（灰度化、二值化、降噪）

### 3. 任务执行层 (`src/tasks/`)
- 任务生命周期方法是否完整实现
- 异常恢复路径是否覆盖所有可能的错误状态
- 循环逻辑是否有退出条件（防止无限循环）
- 体力/资源检查是否在 `pre_check()` 中完成

### 4. 调度层 (`src/scheduler/`)
- 任务优先级排序是否正确
- 并发任务是否有资源冲突
- 定时任务的时区处理

### 5. 配置管理 (`src/config.py`)
- pydantic 模型是否有合理的默认值和校验规则
- 配置热重载是否安全
- 敏感配置（如通知 token）的处理

## 常见问题检查清单

- [ ] 是否有硬编码的坐标/路径？应提取到配置或常量
- [ ] 异步函数是否有正确的 `await`？
- [ ] 日志级别是否合理？（debug/info/warning/error）
- [ ] 是否有资源泄漏风险？（文件句柄、ADB 连接）
- [ ] 是否处理了 `KeyboardInterrupt`？长时间运行的任务应优雅退出
- [ ] 循环中的 `sleep()` 是否合理？避免过于频繁的设备操作
- [ ] 模板图片路径是否使用了相对路径？
- [ ] 类型注解是否完整？
